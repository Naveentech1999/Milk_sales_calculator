# Daily Milk Sales Calculator

An installable web app for tracking daily Heritage, Vijaya, and Amul milk packet sales.

## Features
- Enter packet quantities by product and date.
- Calculates brand totals, daily sales, packet count, and litres.
- Change product prices in Settings.
- Optional UPI payment request; enter your UPI ID in Settings.
- Mark payment received only after verifying it in your UPI or bank app.
- Print or save an invoice as PDF.
- Local browser storage and offline caching after first load.

## Publish with GitHub Pages
1. Open repository Settings, then Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for the Pages URL to appear. It will usually be https://naveentech1999.github.io/Milk_sales_calculator/

## Install on Android
Open the published HTTPS URL in Chrome, open the browser menu, and choose Install app or Add to Home screen.

## Important
- Sales data is stored in the browser on each device; it does not automatically sync between phone and computer.
- A UPI link opens a payment app. This app does not verify bank transactions or process payments.
- Starter prices should be checked and edited in Settings before use.
- This is a web app, not a Play Store APK.
